📌 行程核心

DAY 1：台北 → 魚池午餐 → 貓藍 → 向山 → 水社 → 晚餐 → 早睡

DAY 2：早餐 → 退房寄行李 → 泳渡 → 回貓藍洗澡拿行李 → 午餐 → 伊達邵 → 提前晚餐 → 18:30 離開 → 台北

最重要：星期日 18:30 前離開日月潭，目標 21:30 抵達台北，預留塞車緩衝，最晚 22:00 到家。

🎒 泳渡前一晚準備

  • 泳衣、泳帽、毛巾、拖鞋
  • 換洗衣物、防曬、防水袋、手機防水套
  • 水、運動飲料、香蕉、飯糰或麵包
  • 星期六晚上整理好星期日退房後所有行李
  • 星期日 06:40 前完成整理，07:00 左右出發

⚠️ 重要提醒

  • 9/20 是大型泳渡活動日，交通、人潮與停車狀況可能和平日差很多。
  • 實際報到、集合、接駁與交通管制時間，以主辦單位最後公告為準。
  • 星期六不要安排登山、環湖自行車或過度耗體力的活動。
  • 星期日泳渡後雖可回貓藍洗澡，但不能躺床休息，因此把休息安排在午餐時段。
  • 18:30 離開日月潭是回台北 22:00 前到家的安全線。
